# Shared context

Background that more than one task needs: the organisation, the people, standing facts.
Anything here is background for every task, not a deliverable, and not owned by any single task folder.

Read what is relevant here before asking the user for context they have already given.

## Rules

- One subject per file, named after the subject, no sequence numbers. Sequence numbers belong to task steps.
- Keep it to context that is stable and reusable. Task-specific working notes stay in the task folder.
- When a fact here goes stale, update it here rather than patching a copy inside a task.
