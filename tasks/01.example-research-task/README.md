# Example: Research Task

This folder is a worked example showing how a multi-step research task is organised in this template.

A task folder contains numbered **step folders**. Each step folder holds the work, notes, and deliverables for one round of work. When the user asks for a new round, a new step folder is added with the next number.

Structure shown here:

```
01.example-research-task/
├── README.md                  ← what this task is about (this file)
├── 01-initial-findings/
│   ├── notes.md               ← research notes
│   └── index.html             ← rendered deliverable (Tailwind)
└── 02-deep-dive/
    ├── notes.md
    ├── index.html
    ├── source-code/           ← helper scripts worth keeping
    │   └── fetch.js
    └── temp/                  ← throwaway intermediate artifacts
```

Delete this example once you're comfortable with the layout.
